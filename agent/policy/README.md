# Policy

Este diretório guarda regras completas para o agente.

## Como usar

- mantenha as policies curtas e estáveis;
- prefira uma policy por tema;
- não use a policy como log de progresso;
- não misture evidência temporária com regra durável.

## Índice

- `agent-workflow.policy.md`: fluxo de trabalho, validação e handoff;
- `spec-stat.policy.md`: relação entre contrato e estado;
- `official-documentation.policy.md`: regra de documentação oficial viva;
- `workspace.policy.md`: organização do workspace operacional;
- `commit-safety.policy.md`: segurança e higiene de commits.
- `session-event-contract.policy.md`: regras de correlacao, renderizacao e persistencia para sessoes e eventos.
