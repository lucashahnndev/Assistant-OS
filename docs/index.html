Bem-vindo ao Atlas Bot

Atlas Bot (anteriormente Assistant-OS) é um Agente de Sistema Proativo projetado para Linux. Diferente de assistentes tradicionais, o Atlas utiliza um Cérebro Agêntico (LLM) para raciocinar, planejar e executar tarefas complexas através de múltiplos canais (Voz, Texto, Navegador).

Status: O projeto está em fase de Estabilização do Core e Expansão de Habilidades.

Funcionalidades Principais

🧠 Cérebro Agêntico

Loop de Raciocínio (ReAct) que permite ao Atlas entender intenções complexas e planejar múltiplos passos.

💬 Integração Telegram

Controle total via chat: envie comandos de texto, receba respostas e troque arquivos (imagens/docs).

🌐 Navegação Autônoma

Controle de navegador via Playwright para pesquisar na web, tocar música e interagir com sites.

💾 Memória Persistente

Sistema de memória de curto e longo prazo (Vector DB) para lembrar de preferências e conversas passadas.

Arquitetura Modular

O sistema é construído sobre uma arquitetura Kernel-Driver, permitindo que novas interfaces (como Discord ou Home Assistant) sejam adicionadas como plugins sem alterar o código principal.

Contribuição

O projeto é Open Source. Consulte Arquitetura para entender como criar novos Drivers ou Skills, e Relatórios para acompanhar auditorias e análises.

As specs normativas canônicas do agente e do sistema vivem em agent/specs/; esta area de docs/ serve como documentação humana e de navegação.
