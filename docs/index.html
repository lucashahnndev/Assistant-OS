Assistant-OS

O Assistant-OS é uma plataforma open-source para a criação de agentes de IA operacionais e seguros, voltados para ambientes Linux e além. Ele foi projetado para atuar não apenas como um chatbot, mas como um Sistema Operacional Agêntico, com separação estrita entre raciocínio e execução.

Nota Arquitetural Crítica: Neste sistema, Modelos de Linguagem (LLMs) NÃO executam ações diretamente. Eles apenas geram intenções. Toda a execução ocorre em um ambiente assíncrono rigorosamente controlado através de Drivers e Capabilities.

Filosofia e Princípios Fundamentais

A arquitetura do Assistant-OS se baseia nos seguintes pilares operacionais:

  • A Interface Nunca Bloqueia: O loop principal de conversação (`Main`) apenas roteia mensagens e reage a eventos. Tarefas demoradas jamais congelam a interação com o usuário.
  • Execução Isolada (Workers): Cada nova tarefa pesada (uma *Work*) roda em seu próprio processo ou *thread* isolada via um `WorkerManager`.
  • Semântica > Coordenadas: Ferramentas como o controle de navegador utilizam árvores de acessibilidade e extração estruturada de DOM em vez de cliques cegos baseados em pixels.
  • Contratos Explícitos: As habilidades (*Capabilities*) do agente não são meros scripts improvisados; elas operam sobre contratos de dados tipados (`contract_v1.py`) com políticas de acesso vinculadas (ACL).
  • Model Context Protocol (MCP): A plataforma abraça padrões de mercado como MCP para injetar dinamicamente ferramentas de contexto, isolando ambientes de execução externos (como o Playwright).

Visão Alto-Nível dos Componentes

Para entender o sistema como um todo, é preciso separar logicamente os componentes em três camadas:

  1. Core Cognitivo e de Agendamento: Onde residem o `Agent Orchestrator` e o `Scheduler`. Responsáveis por interpretar a fala do usuário, quebrar em planos lógicos e enfileirar as tarefas.
  2. Camada de Execução de Tarefas (Capabilities): O conjunto massivo de habilidades (`wikipedia_search`, `browser_control`, `calendar`) que cumprem contratos bem definidos.
  3. Camada de Interface (Drivers): Os adaptadores que conectam o cérebro agêntico ao mundo físico (Telegram, Voice, System, Server).
