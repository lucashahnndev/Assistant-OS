Arquitetura do Sistema

O Atlas Bot utiliza uma arquitetura híbrida Kernel-Driver + Agentic Cognitive Loop. Isso separa o controle de hardware (Drivers) do raciocínio complexo (Orchestrator).

Componentes Principais

Kernel (src/main.py)

O despachante central. Ele não "pensa", apenas roteia. Recebe inputs dos Drivers e os encaminha para o Orchestrator. Recebe ações do Orchestrator e as delega para os Drivers (ex: "Fale isso", "Abra aquilo").

Agent Orchestrator (src/core/orchestrator.py)

O Cérebro. Substitui o antigo "Router". Utiliza um Loop de Raciocínio (ReAct) para:

  1. Analisar o input (Intenção).
  2. Consultar memórias passadas.
  3. Planejar passos (Plan).
  4. Executar ferramentas (Skills).

Drivers (src/drivers/)

Adaptadores de I/O:

  • VoiceDriver: Interface PyGame + STT/TTS local.
  • TelegramDriver: Bot assíncrono para controle remoto.
  • BrowserDriver: Automação web via Playwright (Headless/Headed).
  • ServerDriver: (Experimental) API para controle externo.

Memory System (src/services/memory/)

O Atlas possui persistência de contexto:

  • Session: Mantém o contexto da conversa atual.
  • Long-Term: ChromaDB armazena embeddings para lembrar fatos e preferências.
