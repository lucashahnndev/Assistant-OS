# Concepts

Este diretorio guarda conceitos, visoes e notas de produto que ainda nao sao contrato formal nem relatorio de auditoria.

## Uso

- ideias de produto;
- exploracoes conceituais;
- propostas ainda em consolidacao.

## Regra

Se um conceito amadurecer para contrato, mova para `agent/specs/` ou para a documentacao tecnica apropriada.
