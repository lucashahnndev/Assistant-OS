Referência de Módulos

Abaixo estão os módulos principais que compõem o ecossistema do Atlas Bot.

Core (src/core)

orchestrator.py (AgentOrchestrator)

O Cérebro Agêntico. Implementa o loop de raciocínio, gerencia a memória de curto prazo e decide qual ferramenta usar.

intent.py (AgentIntent)

Estrutura de dados que normaliza a saída do LLM (Thought, Action, Params).

Drivers (src/drivers)

Interfaces de I/O (Herdeiros de BaseDriver):

telegram_driver.py

Conexão assíncrona com API do Telegram. Suporta texto, comandos e arquivos.

browser_driver.py

Automação web via Playwright. Permite navegar, interagir com elementos e controlar mídia (YouTube).

voice_driver.py

Interface local Legacy (PyGame). Gerencia STT/TTS.

server_driver.py

Stub para futura API REST/WebSocket.

Services (src/services)

llm/manager.py

Gerencia provedores de IA (OpenAI, Ollama, DeepSeek). Trata erros e rate limits.

memory/

Serviços de persistência: ChromaDB (Vetorial) e SessionManager (Contexto).

tts/manager.py

Gerenciador de Síntese de Voz (EdgeTTS, System).

Skills (src/skills)

Habilidades documentadas para uso do LLM:

  • send_file.md: Envio de anexos.
  • youtube_control.md: Busca e reprodução de vídeo.
  • search_web.md: Pesquisa Google.
