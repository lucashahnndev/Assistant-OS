Guia de Instalação

Siga os passos abaixo para configurar o Atlas Bot no seu sistema Linux.

Requisitos: Python 3.12+, `ffmpeg`, `portaudio19-dev`.

Passo 1: Clonar o Repositório

git clone https://github.com/lucashahnndev/Assistant-OS.git
cd Assistant-OS

Passo 2: Configuração

1. Crie o ambiente virtual e instale dependências:

./start.sh

O script irá criar a `env`, instalar os pacotes via `pip` e baixar os navegadores do Playwright.

Passo 3: Credenciais (.env)

Crie um arquivo .env na raiz do projeto com as chaves:

OPENAI_API_KEY=sk-...
TELEGRAM_TOKEN=123456:ABC-DEF...
GROQ_API_KEY=...

Passo 4: Executar

Para iniciar a assistente:

./start.sh

Solução de Problemas

Se tiver problemas com áudio (PyAudio), instale as bibliotecas do sistema:

sudo apt install python3-pyaudio portaudio19-dev
