# Vision Discoverability

Use this capability when the user asks about images, screenshots, or visible screen content.

## When to use
- Analyze an image or screenshot
- Locate UI elements visually
- Describe what is visible on screen
- Extract text or inspect regions in a screenshot

## When not to use
- Pure text lookup
- Browser navigation unless the user explicitly wants browser interaction
- Calendar, weather, or memory tasks

## Discovery clues
- vision, image, screenshot, screen, visual, ocr, tela, imagem, analyze image
