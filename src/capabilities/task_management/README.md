# Task Management Discoverability

Use this capability for task notes, schedulers, triggers, and work orchestration.

## When to use
- Create or update tasks
- Schedule or run triggers
- Inspect task lists, notes, or work queues
- Manage planning-oriented workflows

## When not to use
- Personal memory storage
- Calendar events
- Internal agenda or calendar lookups
- Browser navigation
- External research

## Discovery clues
- task, scheduler, workflow, trigger, notes, job, queue, plan, work
