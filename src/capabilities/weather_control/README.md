# Weather Control Discoverability

Use this capability for current weather, forecast, and location-based weather questions.

## When to use
- Current weather conditions
- Forecast by city, region, or location
- Weather summaries and alerts

## When not to use
- General knowledge questions
- Browser navigation just to check weather pages
- Calendar, memory, or system tasks

## Discovery clues
- weather, clima, tempo, forecast, previsao, previsão, chuva, temperatura, vento, city weather
