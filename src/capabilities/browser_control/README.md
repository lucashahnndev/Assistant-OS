# Browser Control Discoverability

Use this capability only when the user explicitly wants browser or UI interaction.

## When to use
- Open a site or page
- Click, type, scroll, or select elements
- Automate a browser tab or visible UI
- Inspect the current page visually or interactively

## When not to use
- Pure information lookup
- Calendar, weather, memory, or system tasks that already have a specialized capability
- Generic search when a dedicated search/retrieval capability exists

## Discovery clues
- browser, web, site, page, tab, ui, tela, clicar, navegar, preencher, scroll
